# Plattformübergreifende Rechner-App

Dieser Bereich ist für die gemeinsame Flutter-App für Android, iPhone/iPad, Windows, macOS und Linux vorbereitet. Noch kein ausführbares Flutter-Projekt; Plattformdateien werden nach Prüfung des stabilen SDKs erzeugt.

Hier liegen später Oberfläche, Eingabeadapter, Plattformintegration und die Verbindung zum lokalen Paket `packages/calculator_core`. Mathematische Auswertung und Rechnerzustände bleiben im Core.

Verbindlicher Entwurf: [Projektstruktur](../../docs/PROJEKTSTRUKTUR.md). Die Originalsoftware ist keine Voraussetzung für das erste eigene Grundgerüst.
