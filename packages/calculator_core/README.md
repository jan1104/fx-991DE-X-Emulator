# Unabhängiger Rechenkern

Dieser Bereich ist für ein reines Dart-Paket vorbereitet. Es enthält noch keine implementierten Rechnerfunktionen.

Geplant sind Zahlenmodelle, Ausdrucksbaum, logischer Editor, Rechnerzustand, Auswertung und strukturierte Ausgabedaten. Keine Flutter-Imports und keine Betriebssystem-, Netzwerk- oder Dateizugriffe. Die Flutter-App verwendet ausschließlich eine kleine öffentliche Paket-API.

Eigene Tests werden hier neben dem Paket geführt. Die geplanten Referenzfälle aus `docs/REFERENZTESTS.md` dienen als Grundlage; ihr bisheriger Status bleibt geplant.

Siehe [Projektstruktur](../../docs/PROJEKTSTRUKTUR.md).
